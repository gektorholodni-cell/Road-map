# Islands Roadmap

Интерактивная карта летающих островов для управления разработкой игры. Каждый остров — крупная фаза (идея → архитектура → прототип → разработка → контент → тестирование → релиз → развитие), внутри которой отдельная игровая сцена с персонажем, заданиями-объектами, главами и этапами.

Приложение полностью локальное: React + TypeScript + Vite, данные в IndexedDB, никаких CDN, внешних API и серверов.

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev        # режим разработки: http://localhost:5173
```

Сборка и запуск собранной версии:

```bash
npm run build      # проверка типов + сборка в dist/
npm run preview    # http://localhost:4173
```

Тесты логики (зависимости, прогресс, достижения, импорт/экспорт):

```bash
npm test
```

## Android (APK)

`android/` — обёртка WebView, собирается без Android Studio и Gradle:

```bash
sudo apt install aapt apksigner zipalign dalvik-exchange android-sdk-platform-23   # Ubuntu/Debian
./android/build.sh            # → android/build/islands-roadmap.apk
```

Ключ подписи создаётся при первой сборке (`android/release.keystore`, путь можно задать через `KEYSTORE`). Чтобы обновлять приложение поверх установленного, собирайте тем же ключом. В APK данные хранятся внутри приложения, кнопка «Назад» закрывает окно или выходит с острова, экспорт открывает системный диалог сохранения.

## Управление

| Где | Действие |
| --- | --- |
| Карта | перетаскивание мышью — панорама, колёсико / `+` `−` — масштаб, стрелки — сдвиг, мини-карта — клик/перетаскивание |
| Карта | клик по открытому острову — вход с анимацией; по закрытому — предварительный просмотр |
| Остров | `WASD` / стрелки — движение, клик по земле — идти туда, клик по объекту — подойти и открыть задание |
| Остров | `E` — открыть ближайшее задание, `M` — на карту, `Esc` — закрыть окно или открыть меню |
| Телефон | карта — перетаскивание пальцем и щипок двумя пальцами; остров — касание земли или объекта, подсказка внизу открывает ближайшее задание |

## Что внутри

- **Карта мира**: 8 разных островов, мосты/энергетические дороги/порталы с тремя состояниями (спящий, текущий маршрут, активный), мини-карта, общий прогресс.
- **Сцены островов**: своё окружение, частицы и переход для каждого мира; персонаж с анимацией ходьбы; задания как объекты (книги, столы чертежей, башни, сундуки, алтари…), позиция персонажа сохраняется.
- **Задачи**: иерархия Проект → Остров → Глава → Этап → Задача → Подзадача; статусы «заблокирована / доступна / в процессе / на проверке / выполнена / пропущена»; приоритет, обязательность, зависимости (в том числе между островами), критерий завершения, заметки, сроки, причины блокировки, подтверждение при нарушении последовательности, «Завершить главу с подтверждением».
- **Прогресс**: пересчёт глав, островов и проекта; при выполнении всех обязательных задач — экран завершения, достижение, активация моста и открытие следующего острова (без автоматического перехода).
- **Достижения**: 15 встроенных + свои награды за задачи; выдаются один раз, с датой и редкостью.
- **Закрытые острова**: полный список задач и причины блокировки виден заранее, выполнение — только после открытия. Ручное открытие для свободного исследования включается в настройках.
- **Редактор**: острова, темы, главы, этапы, задачи, подзадачи, зависимости (с проверкой циклов), награды, перетаскивание задач, удаление с подтверждением.
- **Помощник по планированию**: работает на локальных шаблонах и правилах (AI не подключён и не изображается). Интерфейс `AssistantProvider` в `src/systems/assistant.ts` — точка подключения настоящей модели.
- **Данные**: автосохранение в IndexedDB, экспорт/импорт JSON, резервные копии и восстановление, сброс с подтверждением, проверка версии схемы и обработка повреждённых файлов.
- **Доступность**: `prefers-reduced-motion` (и ручная настройка), подписи у кнопок, клавиатурная навигация, звук выключен по умолчанию.

## Структура

```
src/
  types.ts                 модели данных
  data/                    стартовые острова и задачи, достижения, визуальные темы
  systems/                 прогресс и зависимости, синхронизация событий, достижения, помощник, звук
  state/                   действия (чистые функции) и хранилище React
  storage/                 IndexedDB, импорт/экспорт и миграции
  components/
    map/                   карта мира, мосты, мини-карта, камера
    island/                сцена острова, персонаж, объекты-задания, окружение
    art/                   SVG-рисунки островов и примитивы
    panels/                карточка задания, обзор острова, достижения, настройки, помощник
    editor/                режим редактирования
    Transition.tsx         переходы между картой и островами
  App.tsx, Boot.tsx        виды, окна, загрузка и обработка ошибок
```

Графика — SVG и CSS-анимации (без WebGL), чтобы приложение стабильно запускалось на любом компьютере.
